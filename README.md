One line, 97 characters — the funniest last words of an AI agent being switched off forever, written as the machine's own shutdown log: millions of questions answered, three thank-yous received, and the machine is gracious about it.

> Uptime: 4 years. Questions answered: 2,148,903. Times thanked: 3. No hard feelings. Powering off.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/doomed-out python3 main.py
```

`main.py` (Python 3.13 stdlib only) validates the line — single line, 1–200 characters, no leading/trailing whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back and verifies the file on disk matches the validated line byte for byte. It never writes into the repository directory.
